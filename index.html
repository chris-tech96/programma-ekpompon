Πηγή δεδομένων: Google Sheets — ένα φύλλο ανά εκπομπή

Το Google Sheet σου

Μοιράσου ολόκληρο το βιβλίο μία φορά (Κοινή χρήση → «Όποιος έχει τον σύνδεσμο» → Θεατής) και βάλε το link του Google Sheet εδώ.

Πού βρίσκω το API key; (μία φορά, δωρεάν)

Google Cloud Console → δημιούργησε ένα project → APIs & Services → Library → Google Sheets API → Credentials → Create Credentials → API key.

Χωρίς API key: γράψε τα ονόματα καρτελών χειροκίνητα
Προχωρημένο: Εγγραφή πίσω στο Google Sheet (όταν προγραμματίζεις ένα επεισόδιο, σημειώνει αυτόματα την ημερομηνία στο sheet)

Αυτό λειτουργεί μόνο αν το αρχείο "τρέχει" από πραγματική διεύθυνση (όχι διπλό κλικ στο αρχείο), και απαιτεί ένα δικό σου OAuth Client ID (διαφορετικό από το API key).

Πώς φτιάχνω OAuth Client ID;

Google Cloud Console → το ίδιο project όπου έφτιαξες το API key → APIs & Services → Credentials → Create Credentials → OAuth client ID → τύπος "Web application" → στο "Authorized JavaScript origins" πρόσθεσε ακριβώς τη διεύθυνση απ' όπου θα ανοίγεις αυτό το αρχείο (π.χ. https://username.github.io ή http://localhost:8000). Αντέγραψε το Client ID που θα σου δώσει (τελειώνει σε .apps.googleusercontent.com).

Προσθήκη μεμονωμένης εκπομπής με δικό της link

Εβδομαδιαίο πρότυπο

Η εβδομάδα πάει Δευτέρα → την επόμενη Δευτέρα (8 στήλες). Οι πρώτες 7 είναι το πρότυπο (επαναλαμβάνεται κάθε εβδομάδα). Η 8η (επόμενη Δευτέρα) είναι η πραγματική επόμενη ημερομηνία — δείχνει αρχικά ό,τι έχει το πρότυπο, αλλά μπορείς να την αλλάξεις ξεχωριστά χωρίς να πειράξεις το πρότυπο. Οι ώρες έναρξης μένουν σταθερές και η ώρα λήξης υπολογίζεται από τη διάρκεια του επεισοδίου.

Ο μήνας γεμίζει από το εβδομαδιαίο πρότυπο. Μπορείς να κάνεις μεμονωμένη αλλαγή σε συγκεκριμένη ημερομηνία χωρίς να αλλάξεις το πρότυπο.

Νέα ζώνη

Επίλεξε επεισόδιο για να δεις την ώρα λήξης.
